# MORROWMERE visual assets

The 68 optimized source plates in this directory were generated specifically for MORROWMERE with OpenAI image generation and refreshed on 2026-08-31. They contain no third-party game artwork, logos, or copied user-interface elements.

- `backgrounds/`: one title plate, four fallback region plates, and one web splash plate
- `events/`: 48 distinct illustrated event backgrounds, one for every authored event
- `enemies/`: ten encounter plates covering all bestiary art families
- `onboarding/`: three feature illustrations for chronicle, combat, and loadout guidance
- `icons/`: the master square app icon

The runtime selects the exact event illustration and presents it without artificial weather, grain, darkening, or decorative overlays. The refreshed artwork uses clear focal subjects, clean atmosphere, and midtone-rich daylight or lamplight so it remains readable on a phone. Enemy encounters retain a distinct treatment key for each of the 200 bestiary entries.
