# MORROWMERE visual assets

The sixteen source plates in this directory were generated specifically for MORROWMERE with OpenAI image generation on 2026-08-30. They contain no third-party game artwork, logos, or copied user-interface elements.

- `backgrounds/`: one title plate and four region plates
- `enemies/`: ten encounter plates covering all bestiary art families
- `icons/`: the master square app icon

The runtime compositor deterministically varies crop, mirror, weather, lighting, hue, scale, and contrast. This produces 300 enumerated environment combinations and a distinct treatment key for each of the 200 enemy entries while keeping the installed app compact.
