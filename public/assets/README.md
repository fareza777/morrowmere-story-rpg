# MORROWMERE visual assets

The 68 optimized source plates in this directory were generated specifically for MORROWMERE with OpenAI image generation on 2026-08-30. They contain no third-party game artwork, logos, or copied user-interface elements.

- `backgrounds/`: one title plate, four fallback region plates, and one web splash plate
- `events/`: 48 distinct illustrated event backgrounds, one for every authored event
- `enemies/`: ten encounter plates covering all bestiary art families
- `onboarding/`: three feature illustrations for chronicle, combat, and loadout guidance
- `icons/`: the master square app icon

The runtime compositor selects the exact event illustration first, then applies restrained crop, lighting, and color treatment. Weather layers use coherent gradients and rain rather than decorative speckle overlays. Enemy encounters retain a distinct treatment key for each of the 200 bestiary entries.
