# MORROWMERE privacy policy

Effective date: 1 September 2026

MORROWMERE is a single-player game. The story, artwork, music, sound effects, and core gameplay are stored in the application and can be used offline. Game progress, settings, and any player-entered character name are stored locally on the device. MORROWMERE does not provide user accounts and does not upload these local saves to a developer server.

The Android edition uses Google Mobile Ads to display banners, interstitial ads, and optional rewarded ads. Google states that its Mobile Ads SDK automatically collects and shares information including the device's IP address, product interactions, diagnostic information, and device or account identifiers. An IP address may be used to estimate general location. Google uses this information for advertising, analytics, and fraud prevention, and states that data is encrypted in transit.

Where required, the game requests updated consent information at launch through Google's User Messaging Platform before requesting ads. A privacy-options control is displayed when Google reports that it is required. Choosing not to view a rewarded ad does not block story progress or combat rewards. If an ad or network request fails, the core game remains playable.

MORROWMERE itself does not include a developer-operated analytics service, account system, social login, or remote save service. Uninstalling the game or clearing its storage deletes local game data, subject to Android or device backup behavior.

This game is not designed for children. The publisher must keep its Google Play target-audience, ads, and Data safety declarations consistent with the exact production configuration.
